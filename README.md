## Documentation approach

- Explain the user problem and constraints before the implementation.
- Record the alternatives, chosen behavior and operational trade-offs.
- Separate existing product behavior, measured results and proposed changes.
- Use synthetic examples where real accounts, conversations or balances would be inappropriate.
